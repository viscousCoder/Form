# User Regestration From

This is user regestration form in which user deatils should be filed in the form and it is saved in the local storage and then from local storage all the user data is fetched and shown in the table section.

## Description

The Form consist of some features:

1. **Regex function**:There is a custom regex functio to the each filed in the form.
2. **Tiimmer**: There is a watch at the top of the form where date,month, year and tine is shown.
3. **Dynamic Dropdown**: According to the selected state, that particular district will be shown to the user in the next dropdown slected box.
4. **Local-storage**: When user successfully submit the from the form its details has been saved in the local storage..
5. **Table Section**: All users data is shown in the table section.
6. **Action in the table**: User can edit the data with the edit button which take the user details to the form and then user can update its data, User can also delete its data which and user can view its data in the js modal.

## Navigation Bar Functionality

The navigation bar is linked to specific sections for easy access:

- **Logo**: Redirects to the Welcome section.
- **Form**:Take the user in form section.
- **Table**: Take the user in the table sectionb.
